D. Apersepsi

Bayangkan kamu sedang membuat aplikasi data siswa. Program perlu mengetahui nama siswa, kelas, umur, nilai, dan jurusan.

Nama siswa = "Budi"
Kelas = "XI RPL 1"
Umur = 16
Nilai = 85

Menurutmu, bagaimana cara menyimpan informasi tersebut di dalam program?

Informasi tersebut dapat disimpan menggunakan variable. Setiap variable memiliki nama dan nilai, misalnya let nama = "Budi"; atau let umur = 16;.

E. Aktivitas 1 – Mengamati

Perhatikan kode berikut dan jalankan menggunakan browser.

let nama = "Budi";
let umur = 16;
let nilai = 85;

console.log(nama);
console.log(umur);
console.log(nilai);

Pertanyaan dan Jawaban

1. Apa yang ditampilkan pada Console?

2. Menurutmu, apa fungsi nama, umur, dan nilai?

Ketiganya adalah variable yang digunakan untuk menyimpan data nama, umur, dan nilai.

3. Apa yang terjadi jika kode console.log(nama); dijalankan?

Console menampilkan nilai yang tersimpan di dalam variable nama, yaitu Budi.

4. Menurut dugaanmu, apa yang dimaksud dengan variable?

Variable adalah tempat untuk menyimpan data agar dapat digunakan kembali oleh program.

Variable dapat dianggap sebagai tempat untuk menyimpan sebuah data agar data tersebut dapat digunakan kembali oleh program.

G. Aktivitas 3 – Praktik Membuat Variable

Buat file variable.html, kemudian masukkan kode berikut. Buka file menggunakan browser, lalu klik kanan → Inspect → Console.

J. Aktivitas 6 – Mengenal let dan const

let umur = 16;
umur = 17;
console.log(umur);

Hasil:

Kesimpulan Sementara

KeywordNilai dapat diubah?Kegunaan sederhana
letYaUntuk data yang masih mungkin berubah.
constTidak dapat di-assign ulangUntuk data yang tidak perlu diubah.

Contoh penggunaan let:

let nilai = 80;
nilai = 90;

Contoh penggunaan const:

const namaSekolah = "SMKN 1 Garut";

K. Aktivitas 7 – Aturan Penamaan Variable

Diperbolehkan:

let nama;
let namaSiswa;
let nama_siswa;
let nilai1;

Tidak diperbolehkan:

let 1nama;
let nama siswa;
let nama-siswa;

JavaScript membedakan huruf besar dan kecil (case-sensitive). Jadi nama berbeda dengan Nama.

let nama = "Andi";
console.log(nama); // benar
console.log(Nama); // error jika Nama belum dibuat
